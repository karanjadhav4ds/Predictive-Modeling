# Predictive-Modeling

# Predictive Modeling Using Regression

## Overview
This project demonstrates a supervised machine learning workflow using Python and Scikit-learn. It applies Linear Regression to retail transaction data and covers preprocessing, feature preparation, model training, prediction, and evaluation.

## Key Features
- Dataset preparation and target-variable creation
- Numerical and categorical feature preprocessing
- Missing-value imputation and numerical scaling
- Categorical encoding
- Feature selection
- Training and testing data split
- Linear Regression model training
- Evaluation using MAE, RMSE, and R²
- Actual-versus-predicted plots and residual analysis
- Sample predictions and model outputs

## Technologies Used
- Python
- Pandas and NumPy
- Scikit-learn
- Matplotlib and Seaborn
- Jupyter Notebook

## Skills Demonstrated
Machine Learning, Linear Regression, Data Preprocessing, Feature Selection, Model Evaluation, Prediction, and Residual Analysis.

## Project Purpose
The goal is to understand the major stages of a regression workflow and learn how to evaluate model predictions using appropriate metrics.

## How to Run
1. Clone or download this repository.
2. Install the required Python libraries.
3. Open the notebook in Jupyter Notebook.
4. Ensure the required dataset is accessible and update its path if necessary.
5. Run the notebook cells in sequence.

## Limitation
Revenue is calculated as quantity multiplied by unit price, and these variables are also used as predictors. Therefore, this project primarily demonstrates a regression workflow rather than a reliable future-sales forecasting system. Strong model performance should not automatically be interpreted as evidence of forecasting ability.
